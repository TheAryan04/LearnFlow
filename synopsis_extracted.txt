1. Title of the Project
LearnFlow — A Learning Management System with Student & Admin Dashboard
(Using MERN Stack: MongoDB, Express.js, React.js, Node.js)
2. Introduction and Objectives of the Project
2.1 Introduction
LearnFlow is a full-stack web-based Learning Management System (LMS) developed using the MERN stack — MongoDB, Express.js, React.js, and Node.js. The platform is designed to digitize and streamline the complete academic workflow of an educational institution, bridging the gap between students, instructors, and administrators through a single, unified digital platform.
In today's digital era, educational institutions face growing challenges in managing course content, tracking student progress, conducting assessments, and maintaining academic records efficiently. Traditional paper-based or fragmented systems are error-prone, time-consuming, and difficult to scale. LearnFlow addresses these problems by offering a centralized, role-based platform where students can access course materials and submit assignments, instructors can manage course content and evaluate performance, and administrators can oversee the entire institution's academic operations from a dedicated dashboard.
The system is directly inspired by the real-life needs of students and institutions like IGNOU, where managing courses, assignments, attendance, and results digitally is a genuine operational requirement. The project covers the full Software Development Life Cycle (SDLC) — from requirements analysis and design to development, testing, and deployment.
2.2 Objectives
Design and develop a full-stack Learning Management System named LearnFlow using the MERN stack.
Implement secure role-based authentication for three user roles: Student, Instructor, and Admin using JWT.
Enable students to browse, enrol in, and track progress across multiple courses on the platform.
Allow instructors to create and manage courses, upload lecture materials (videos, PDFs, notes), and post assignments.
Build an assignment and submission module with deadline tracking, file upload, and instructor grading.
Develop an attendance tracking module enabling instructors to mark and students to view their attendance records.
Create a result and grade management system to publish marks, generate progress reports, and calculate GPA.
Build a comprehensive Admin Dashboard for managing users (students, instructors), courses, and institution-wide reports.
Implement a real-time notification system for assignment deadlines, result announcements, and course updates.
Ensure platform security through bcrypt hashing, JWT authentication, input validation, and HTTPS enforcement.
Deploy the platform on cloud infrastructure: Vercel (frontend), Render (backend), MongoDB Atlas (database).

DFD Level 0 — Context Diagram
The entire LearnFlow system is represented as a single process interacting with four external entities:
Student: Registers/logs in, browses and enrols in courses, views lecture materials, submits assignments, checks attendance and results, receives notifications.
Instructor: Logs in, creates and manages courses, uploads lecture content, posts assignments, marks attendance, grades submissions, publishes results.
Administrator: Manages all users (students & instructors), manages course catalogue, monitors platform activity, generates institution-wide reports.
Cloud Storage (Cloudinary): Receives file upload requests from the system; stores and serves lecture videos, PDFs, and assignment files via CDN URLs.

DFD Level 2 — Sub-Process Detail
Process 1.0 — User Management:
1.1 Registration: Validate inputs → check email uniqueness → bcrypt hash password (salt=10) → save user with role → send welcome email → return 201.
1.2 Login: Find user by email → bcrypt.compare() → generate JWT({id, role}, SECRET, {expiresIn:'7d'}) → return token + role.
1.3 Role Middleware: Extract Bearer token → jwt.verify() → attach req.user → check role (student/instructor/admin) → next() or 403.
Process 4.0 — Assignment Management:
4.1 Post Assignment: Instructor sends {title, description, deadline, courseId} → validate → save Assignment document → trigger deadline notifications to enrolled students.
4.2 Submit Assignment: Student uploads file to Cloudinary → receive URL → save Submission{student, assignment, fileUrl, submittedAt} → return confirmation.
4.3 Grade Submission: Instructor reviews submission → POST /api/submissions/:id/grade → update {marks, feedback} → trigger result notification to student.
Process 5.0 — Attendance:
5.1 Mark Attendance: Instructor sends [{studentId, status}] for a course-date → upsert Attendance documents → return summary.
5.2 View Attendance: Student requests GET /api/attendance/:courseId → aggregate attendance records → return {present, absent, percentage}.

5.3 Process Logic for Each Module
M1 — User Authentication
Register: POST /api/auth/register → validate fields → check email unique → bcrypt.hash(password,10) → save User({role}) → send welcome email → return 201 + user info.
Login: POST /api/auth/login → User.findOne({email}) → bcrypt.compare() → jwt.sign({id,role}, SECRET, {expiresIn:'7d'}) → return token.
Role Guard Middleware: verify JWT → attach req.user → check role → next() or 403 Forbidden.
M2 — Course Management
Create Course (Instructor): POST /api/courses → upload thumbnail to Cloudinary → save Course({instructor: req.user.id, isPublished: false}) → return 201.
Publish Course: PATCH /api/courses/:id/publish → verify ownership → set isPublished: true → notify enrolled students.
Search: GET /api/courses?keyword&category&page → $regex on title/description → .skip().limit() → return {courses, total}.
M3 — Enrolment
Enrol: POST /api/enrolments → check if already enrolled → create Enrolment({student, course, progress:0}) → return 201.
Progress Update: PATCH /api/enrolments/:id/progress → add lessonId to completedLessons → recalculate progress = (completed/total)*100 → save.
M4 — Content / Material
Upload Material: POST /api/materials → upload file to Cloudinary → save Material({course, title, type, fileUrl, order}) → return 201.
Get Course Content: GET /api/materials/:courseId → verify student is enrolled → return ordered materials list.
M5 — Assignment & Submission
Post Assignment: POST /api/assignments → save Assignment({course, title, description, deadline, maxMarks}) → trigger deadline notifications to enrolled students.
Submit: POST /api/submissions → upload file to Cloudinary → save Submission({assignment, student, fileUrl, status:'submitted'}) → return 201.
Grade: PATCH /api/submissions/:id/grade → update {marks, feedback, status:'graded'} → update Result aggregate → notify student.
M6 — Attendance
Mark: POST /api/attendance → instructor sends [{studentId, status}] for courseId + date → bulk upsert Attendance documents.
Report: GET /api/attendance/:courseId/:studentId → aggregate {present, absent, late, percentage} → return attendance summary.
M7 — Results & Grades
Publish Result: POST /api/results → aggregate all graded submissions for student+course → sum totalMarks → compute grade (A:90+, B:75+, C:60+, D:50+, F:<50) → save Result → notify student.
Grade Card: GET /api/results/:studentId → return all course results with grade and remarks → frontend renders downloadable PDF.
M9 — Admin Dashboard
Stats: GET /api/admin/stats → aggregate: total users by role, total courses, total enrolments, active students this month.
User Management: GET/PATCH/DELETE /api/admin/users → list, update role, deactivate, or remove users.

8. Future Scope and Further Enhancement of the Project
Live Virtual Classroom: Integrate WebRTC or third-party APIs (Zoom/Jitsi) to enable real-time live lecture sessions directly within LearnFlow with chat, hand-raise, and screen-sharing features.
AI-Powered Doubt Resolution: Implement an NLP-based chatbot trained on course content to answer student queries, suggest relevant materials, and provide 24/7 academic assistance.
Adaptive Learning Paths: Use machine learning to analyse each student's performance and automatically recommend personalized learning paths, exercises, and revision materials.
Mobile Application: Develop a cross-platform mobile app using React Native for Android and iOS, enabling students to access lectures, submit assignments, and track progress on the go.
Online Quiz & Examination Module: Add a timed online quiz/examination system with MCQ, short-answer formats, auto-evaluation, and instant result display.
Discussion Forum: Introduce a course-level discussion board where students and instructors can post questions, share resources, and collaborate in threaded conversations.
Certificate Generation: Auto-generate and issue digitally signed course completion certificates (PDF) upon students achieving the required progress and grade threshold.
Payment Gateway Integration: Enable paid course enrolments for premium courses offered by guest instructors, with Razorpay/Stripe integration and instructor revenue sharing.
Offline Access (PWA): Convert LearnFlow into a Progressive Web App to support offline reading of downloaded materials and background sync when connectivity is restored.
Multi-Institution Support: Extend the platform to support multiple institutions under a single deployment with isolated data, custom branding, and separate admin panels per institution.
